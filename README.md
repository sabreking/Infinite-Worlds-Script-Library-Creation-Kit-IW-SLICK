# IW-SLICK

**Infinite Worlds Script Library Creation Kit**

A public kit for [Infinite Worlds](https://infiniteworlds.app) world creators.

**Copy modules from the website.** That is the kit. Open a look, press COPY, paste into Infinite Worlds.

**How to use it:** [https://mellow-truffle-5x34.here.now/](https://mellow-truffle-5x34.here.now/)

The JSON in this repo is a backup dump for people who already live in files, and the source we rebuild the site from when a new export ships. Amateurs should not open it.

---

## The Script Library

A contribution from **KaapstadMK**, with pieces from Xyphrax, Thyr, TWNT, Tori, Funky Munky, MrDrunkinDragon, WolfishGrimm, and SpacemanSpiff.

It is a **copy-paste repository**, not a playable game. Copy **one picture script**, the matching appearance notebooks (or none, if the page says the game remembers the face), then only the story or species pieces you need.

| Resource | Where |
|----------|--------|
| Hosted copy-paste kit | [mellow-truffle-5x34.here.now](https://mellow-truffle-5x34.here.now/) |
| Rebuild the site | `python scripts/build_guide.py` (reads the JSON, writes `docs/`) |
| Library JSON (v2.38 backup) | [`library/The Script Library 2.38.json`](library/The%20Script%20Library%202.38.json) |
| Shared Infinite Worlds world | [infiniteworlds.app/shared/7zDKHR](https://infiniteworlds.app/shared/7zDKHR) |

### What the kit contains

- **Eight current picture scripts (pick one):** photos of people, a painting, cheap photos, manga pages, a crowded scene, two people, one person the game remembers, one person with lean language
- **Story voice:** Split Game Master, Storymaster, Author style, Evaluation, Description, Summarization
- **Extra writing rules:** Characterization, Pacing, Sexual Content, Period Knowledge, Narrative Craft, Lion / Leopard
- **Body add-ons** and **creature add-ons**
- **Picture frame words** (Image style prefix and suffix)
- **Never mix these** — the conflict list

Old picture scripts and library-only Foolproofing / Terminate / Safeguard are not on the copy pages. Leave them in the JSON dump.
