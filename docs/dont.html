BACKUP

Never mix these.

Each look page already says what to leave turned off. This page is the full list, in case you come back later and forget which pieces fight.

  • Every turn draws a new picture. Wrangler and Bareback reuse last turn’s written description of the face and clothes when you spell the name the same way. The other picture scripts throw that description away and copy notebooks instead. That is why those two looks get no appearance notebooks, and why the others do.
  • Turn on one picture script in a game. Positional Director, SFW Director, the Unified directors, and Lean Director are all the photograph job. If two of them are on, they write the same picture fields and they contradict each other.
  • Wrangler and Bareback are the same one-person job, the one that reuses the written description. Pick one of them. Leave the other off.
  • Photo, painting, manga, cheap photos, and Bob Ross use Player Appearance and one NPC Appearance list. Wrangler and Bareback use no appearance notebooks. Creating those notebooks on Wrangler or Bareback throws away the saved description that was keeping the face steady.
  • For non-human people, paste Core Only, or paste all seven Non-human parts. Do not paste both. Both together send the shared rules twice every turn.
  • Paste one body add-on. Male, futa, agender, and hypertrophy all describe the same body. If you paste them all, the picture model receives several body plans at once.
  • Use a named picture style, or use the blank image-style template. Do not use both. Both are wrappers around the same picture prompt.
  • Turn on Wyvern Word Caps only when the picture model is Wyvern. It replaces the longer Manticore word limits. On Manticore, leave it off.
  • Do not copy Foolproofing, Terminate, or Safeguard (Library only). Those stay in the library file. They are not meant for a live game, so this site does not give you a paste box for them.
  • The library file lists five sample skills: Empathy, Persuasion, Resilience, Perception, and Resourcefulness. Add those names on the Skills screen only if you want them in your game. They are not picture modules and they are not story modules.
  • Example people in the library file — Blank, Esmé Strandloper, the Hogwarts student, Jeanette Doe clothed, Jeanette Doe naked, and the Harpy test — are samples. Do not paste them into your cast unless you actually want those examples in your game.
  • Do not overwrite Description instructions you already wrote for pictures with the story-voice Description paste. Description is how the story talks. If that field already holds picture instructions, leave it alone.
