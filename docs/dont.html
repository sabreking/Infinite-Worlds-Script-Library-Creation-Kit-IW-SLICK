Never mix these.

Each look page already says what not to turn on. This is the full list.

  • One picture script in a game. Positional Director, SFW Director, the Unified directors, and Lean Director are all the photograph job. Pick one.
  • Wrangler and Bareback are the same remembered-face job. Pick one.
  • Photo, painting, manga, cheap photos, and Bob Ross use Player Appearance and one NPC Appearance list. Wrangler and Bareback use no appearance notebooks.
  • Non-human Core Only, or all seven Non-human parts. Not both.
  • One body add-on. Male, futa, agender, and hypertrophy fight if you paste them all.
  • A named picture style, or the blank image-style template. Not both.
  • Wyvern Word Caps only when the picture model is Wyvern. It replaces the Manticore word limits.
  • Do not copy Foolproofing, Terminate, or Safeguard (Library only). Those stay in the library dump. They are not for a live game.
  • The JSON lists five sample skills: Empathy, Persuasion, Resilience, Perception, Resourcefulness. Add those names on the Skills screen only if you want them. They are not picture or story modules.
  • Example cast rows in the JSON (Blank, Esmé Strandloper, Hogwarts student, Jeanette Doe clothed, Jeanette Doe naked, Harpy test) are samples. Do not paste them into your cast unless you want those examples.
  • Do not overwrite Description instructions you already wrote for pictures with the story-voice Description paste.
