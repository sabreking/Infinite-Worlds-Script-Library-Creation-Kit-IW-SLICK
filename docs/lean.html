<#NPC Appearance#>
Structured appearance and clothing data for significant NPCs, stored as discrete fields for image generation reference. Updated whenever a character's physical appearance or clothing changes.
Update rules (when to change it)
<#NPC Appearance — Large Cast#>
Create entry ONLY when named character in Relationship Tracker marked significant: true; FORBID: create entry if Relationship Tracker empty
Incomplete entry (name field only) -> populate immediately; all entries: ALL fields created + populated
Update appearance fields ONLY on permanent physical changes — including transformative change to body/race/gender/physical features
Appearance fields: permanent physical facts ONLY — FORBID: positional language | scene-specific descriptors | transitional language ("softening into" / "spilled across" / "pressed against")
FORBID: repeat detail already described in a preceding field
distinguishing_features: unique identifying characteristics not captured in preceding fields; FORBID: species-specific non-human features (-> non_human_features)
non_human_features: species-specific non-human characteristics not captured in preceding fields
naked: field gates clothing block — update when naked status changes in outcomeDescription
Update clothing fields whenever clothing changes in outcomeDescription
garments: list of worn items ONLY — name of garment + basic description; FORBID: fit | fabric behavior | wear state | scene-specific positioning | undergarments | accessories
undergarments: list of worn underwear + bra (if applicable) ONLY — name of garment + basic description; FORBID: fit | fabric behavior | wear state | scene-specific positioning
accessories: list of worn accessories ONLY — name + basic description; FORBID: scene-specific positioning
state: current clothing wear condition ONLY — FORBID: scene-specific positioning | pose-dependent descriptions | references to other characters
FORBID: update expressions | emotions | demeanor
Remove entries ONLY if relationship becomes non-significant OR character permanently exits narrative
