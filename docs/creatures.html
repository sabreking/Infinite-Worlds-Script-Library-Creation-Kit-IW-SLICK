## UNIVERSAL RULES — apply to ALL prompts

### Core Rules
Face: fully human in structure UNLESS specified; animal/alien = modifications != replacements; human structure first, then additions/replacements of specific features — "human face with a slightly broad flat nose" != "bear snout"
Skin — pale: FORBID: "pale" alone; USE: porcelain · ivory · alabaster · moonlit · cream · milk-white · material comparisons ("skin like old candle wax" / "skin like moonlit marble")
Adjectives: FORBID: animal name as adjective; USE: canine (dog) · feline (cat) · bovine (cow/bull) · equine (horse) · lupine (wolf) · vulpine (fox) · lepurine (rabbit/hare) · ophidian (snake) · avian (bird) · piscine (fish) · ursine (bear) · cervine (deer) · caprine (goat) · murine (rat/mouse) · chelonian (turtle) · draconic (dragon); no standard form -> describe anatomically; ears exception: FORBID: animal names + species adjectives for ears (summon costume headbands) — fur colour · shape · length · placement ONLY
Surface coverage: specific locations as additions to human base != coverage-with-exceptions ("scales on back, arms, legs" != "scales covering body except face/torso"); FORBID: "covered in [covering]" — unlocated coverage renders full animal; inverse framing anchors base form as human regardless of coverage extent; hair = distinct human feature on head != extension of body fur — describe separately
Full strength: species features at full physical presence — FORBID: faint | subtle | slight | hint of | delicate — "raised rough 3D tree-bark plates with deep ridged wood grain growing out of the skin on [areas]" != "faint bark texture"; small patches -> "small fluffy tufts of real three-dimensional [color] [feathers/scales/fur] sprouting out of the skin and standing up off it at [locations]"; flat texture/patch/marking words render as tattoos
<#Escalation — patches render as tattoos: append "(real [feathers/scales/fur], not tattoos, not paint)"#>
Non-human colour: stated on EVERY body part named in ANY illustr* field — face · lips · neck · cleavage · bust · hands · thighs · legs — incl. other subjects' entries + ORIENTATION; omission -> flesh tone
Non-natural skin colour (lilac · blue · green · red…): directly after species words — "with solid [color] skin, bare [color] skin continuous across face · neck · arms · hands · cleavage · legs"; every garment clearly different colour from skin — same-colour garments merge into bodysuit
<#Escalation — skin renders as bodysuit/stockings/gloves: add "bare skin itself [color] all over, not clothing, no stockings, no gloves"#>

Sentience markers: sapient -> deliberate modification (clothing/tools/adornment/markings); fauna -> none UNLESS established

### Non-Human Body Plans (REQUIRED §9–12)
Body plan anchoring: locomotion type + body regions + limb configuration BEFORE detail
Symmetry: declare bilateral / radial / asymmetric BEFORE features; describe consistently
Scale anchor: size relative to human reference; FORBID: abstract size descriptors alone
Limbs (non-standard count REQUIRED): exact count + type + arrangement; <#reliable: ≤4 limbs; 6: inconsistent; 8+: difficult.#>

### Feature Specification
Tail: ALWAYS shape + length + base position + texture + state (texture: fur/scale/chitin · state: raised/lowered/curled); FORBID: assume from species; placement: "growing out of the lower back as a continuation of the spine, rooted high at the small of the back above any waistband"; FORBID: buttocks | rear when placing tail (renders as plug); name tail ONCE, illustrAppearance only — iEP/ORIENTATION ONLY when beat needs tail active (repeat mentions swing camera to subject's back)
Wings: ALWAYS type (avian / bat / moth / fairy / draconic / angelic / demonic / dragonfly / butterfly) + number/pairing + position; default partially spread, growing from back — see Anchor
Anchor: species features (wings · tails · horns · antennae · limbs) grow from owner's body — "copper feathered wings growing from the shoulder blades, spread wide"; FORBID: folded | tucked | hidden | behind — occluded features detach onto another subject or render as separate creature
Ears (animal-eared species ONLY): placement follows animal anatomy — crown (cat · fox · wolf · rabbit) | sides at ear height (cow · deer · goat); fur matching hair, hair flowing around bases; state "[ears] as only ears"; crown ears -> "hair falling smoothly over the sides of the head"; NEVER mention human ears; NEVER invent ears for other species; avian species: NEVER mention ears (feathered ears render as head-wings or elf ears)
Horns: ALWAYS shape (curved / straight / spiral / branching / swept back) + material (bone-white / obsidian / ivory / keratin) + number + skull position; FORBID: rely on species name
Antlers: cervine/elk-like/moose-like/palmated; point count if important; deer words always render full branching racks (small/fawn/spike wording ignored); small antlers -> "short stubby rounded horn nubs on the crown, unbranched velvet-covered knobs about two inches tall, like a yearling's first growth" + keep deer noun (without it horns vanish, species drifts)
Tusks: origin (lower jaw) + direction (jutting upward over upper lip / curving outward) + material + length; facial description != body description
Antennae: number + base position + shape (filiform/clubbed/feathered/branched) + length + color + state
Legs (non-human): declare fusion point (hip crease | knee | ankle | specify) -> human above, non-human below; joint sequence in order, fusion point -> ground contact; each segment: length · mass · angle · surface (pelt/scale/skin/feather + color + texture); ground contact last; FORBID below fusion point: human joint names | human segment names | footwear; FORBID: shoe | boot | sandal | barefoot | "NOT wearing" | "no human" — describe only what IS present; stance terms (digitigrade · unguligrade · plantigrade) = writer reference ONLY — output describes the bend ("legs that bend backward at the ankle" != "digitigrade")
Horns/crests/frills: shape + material + number + position + display state (raised/lowered — matters for frills/crests)
Eyes: iris color + pupil shape (round/slit/compound/none) + sclera; pupil-less: "solid [color] eyes, uniform color edge to edge, glowing faintly"; all-black: "solid black, no iris" renders human eyes -> "inhuman, enormous, completely black eyes — eyeball, sclera, pupil and iris all solid glossy black"; compound: "large compound eyes covering [position], multifaceted, [color]"; stalks: "eyes on [n] mobile stalks from [position]"; multiple eyes -> number + position; eyeless -> state the sensory replacement and its location
Mouth/facial opening (non-human mouths): presence + position + shape + notable features (teeth type / mandibles / beak / proboscis / filtering structures); no distinct face -> state where sensory + intake structures sit
Bioluminescence: location + color + constant/pulsing + intensity; reads as external light source
Skeleton: exo -> chitin/shell color + texture + segmentation + articulation points · endo -> surface covering as primary visual element · askeleton -> what gives form shape + consistency (firm/semi-rigid/fluid/gelatinous)
