Step 2 — Items to track

Items to track are the notebooks the game keeps between turns. This step tells you which notebooks this look needs.

Create no appearance notebooks.

Every turn, Infinite Worlds draws a brand new picture. It does not reuse the last picture. What this look can reuse is the written description of the person’s face and clothes, and only when you spell their name the same way every time. That saved description is what people mean by the picture cache.

Leave the hidden note that starts “If using appearance tracked items” wrapped. Opening it tells the game to throw the saved description away. The first description has to name the face, the hair, and the colors of the clothes. If that first line is vague, the new picture invents a new person even though the name matches. If someone else is in the scene, put them in the setting. This script is built for one named person.

Step 3 — Fill blanks on what you pasted

Some notes in the script are wrapped in <# … #>. The game skips everything between those marks. The author hid optional packs there — sex scenes, fights, and long clothing rules — so you do not pay for them every turn until you want them. When you want a pack, fill any square brackets inside it, then delete the <# and the #>. When this page tells you to leave a wrap closed, leave it closed.

  • Spell the person’s name the same way every turn. The saved description is tied to that exact spelling. A new spelling looks like a new person, so the face changes.
  • Leave the hidden note that starts “If using appearance tracked items” wrapped. That note is what would throw away the saved description. Do not delete its wrap, and do not create appearance notebooks.
  • There is a slot that says film or painting. Keep the side you want, delete the other side, and then delete the wrap.
  • Find the line with square brackets for period, region, and the kind of artist. Write your choices, then delete the wrap.
  • Find the mood line. Write three to five mood words, then delete the wrap.
  • The first time this person is drawn, name the face, the hair, and the colors of the clothes. Later turns reuse those words. A vague first description gets redrawn as a different person even when the name matches.
  • Sex pose packs and fight pose packs stay wrapped unless your game actually shows those scenes.

Step 4 — Image style

These four boxes are a blank template for the words that wrap the picture. Paste them into the Image style prefix and suffix fields, then keep or delete paragraphs so they match this look.

Those fields go to the picture model only. They do not go to the story writer. That is why you should not paste them into the story Description field. Description is how the story talks. Image style is how the picture looks.

A named style from the Styles page and this blank template are two different wrappers. Use one of them. If you paste both, the picture model receives two looks at once and they fight.

If you would rather start from a finished look, open Styles, pick one, and copy its prefix and its suffix instead of these four boxes.

Keep or delete for this look

  • This look can be photographs or a painting. Keep the paragraphs that match the side you filled in the picture rules. Delete the other side, or both looks will be sent at once.
  • Delete the manga or comic paragraph unless you actually want comic pages. If you want comic pages, the manga look is the better script.
  • If your game does not show sex in the pictures, delete the phrases about sexually stylized art, erotic styling, and genitalia. Those words are instructions to the picture model. Leaving them in will push the pictures that way.
  • A label such as <#TONE#> is a comment. The game ignores the label. The paragraph after the label is live until you delete that paragraph.
