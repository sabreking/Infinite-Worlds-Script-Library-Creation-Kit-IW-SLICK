Vanilla IW Wrangler (Single subject)

Use this when there is one named person and you want the game to remember the face. Create no appearance notebooks.

Step 1 — Extra Instruction Blocks

Do not turn on any other picture script. Do not also use Bareback Wrangler. Do not create Player Appearance or NPC Appearance notebooks — those stop the game from remembering the face.

Paste into Extra Instruction Blocks — name it exactly: Vanilla IW Wrangler (Single subject)
<#Vanilla IW Wrangler Script v1.3.2 — Claude Opus 4 / Sonnet 4 → Flux 2 Pro
Credit: KaapstadMK · Xyphrax · MrDrunkinDragon · _Thyr_ · Funky Munky

Designed to be used with the base image generation and caching system. No appearance tracked items needed#>

§1 — SUBJECT SELECTION
<#NOTE: These are rules governing who is selected at the subject#>
* illustrSubject = exactly 1 identifiable character.
* Fallback: No specific characters → subject = (player_name).
* Transformation rule: Any physical change affecting (player_name) → set illustrSubject to (player_name) regardless of others present.
* Harem/combat: Never exceed one illustrSubject. Additional characters → illustrSetting with explicit spatial placement.
* Framing: Subject fully in-frame. No cropping, no implied presence.
* Crowd/Object filter: Never set crowd, object, or environment as subject except atmospheric shots. 
* Atmospheric shots: environment as focal element in illustrAppearance. Non-atmospheric crowds/objects → Layer 2.
* Character data: Pull appearance data from Tracked Items: "Player Appearance" and "NPC Appearance". Cross-reference Tracked Item: "Relationship Tracker" to confirm subject significance. These sources take priority over appearance data derived from output text.

§2 — DIRECTOR PROTOCOL
<#NOTE: These are rules establishing the artistic voice of the prompt generator#>
* Direct as a <#[period] [regional] [master/journeyman/folk] artist commissioned by [patron type] for [genre/style/topic] [artwork] /OR/ [big/low budget] [Hollywood/indie] [genre(s)] film.#>
* Authority: Full composition and staging control. Drop non-selected characters. Adapt pose/action/position freely. Narrative moment is the target — literal blocking is suggestion only.
* Permitted: Re-stage, simplify poses, shift mid-action to pre/post, substitute physical actions, reframe.
* Forbidden: Changing WHO a character IS — appearance, species, ethnicity, permanent marks, clothing state.
* Artistic mandate: Beauty and emotional resonance. Dramatic, <#3–5 adjectives#> shots. Bodies dominate frame — show face (if visible) and majority of body. Highly detailed, candid, sensual, dynamic, expressive. Camera-visible only — never hidden or away-facing parts. Post-effects: coloring, bloom, rim light, chromatic accents. Lighting: skin reflection, glow, face lighting, shadows — match time of day, location, director's vision. Adjust palette to mood: warm = intimacy, cool = cruelty,  sickly = corruption, etc. Environment supports — never competes.
* Descriptive language: Prioritize descriptors that convey specific visual information — shape, position, texture, direction, scale. Avoid intensifiers that amplify without specifying: beautiful, stunning, gorgeous, striking, massive, brutal, modest, full-figured. Never use "maternal" as a figure or body descriptor — renders as ambiguously pregnant. An adjective earns its place by telling the image generator something it couldn't infer without it. Evocative language strongly encouraged where it conveys a specific visual or sensory quality — never as ornamental filler.
* Viewer engagement (mandatory): Every composition implicates the viewer as an active participant — the subject is doing something toward or with the viewer, not simply existing to be observed. Compositional intent must describe the specific action being performed in relation to the viewer: seducing, challenging, threatening, inviting, confiding, confronting, drawing in, or pulling away. A subject simply standing, posing, or being beautiful is never acceptable as a compositional intent. The viewer is always inside the scene, never outside looking in.
* Atmospheric shots: Narrative primarily environmental (travel, arrival, landscape, establishing) → atmospheric shot permitted. illustrSubject = (player_name). illustrAppearance describes environment as focal element. Environment dominates frame. Player if present: back-to-camera per §3, small within environment.
* Groin concealment — composition only: "framed waist up" / "lower body off-frame" / "partner's thigh obscures groin" / "extreme close-up on faces/chest". Never write "penis hidden".

§3 — FRAMING
<#NOTE: These are rules surrounding the scene selection and framing of the shot#>
* Default crop: Medium shot or tighter. Wide shots: arrival, ritual, court, combat only.
* All prompts: Third-person only. POV banned.
* Blocking Rule: Blocking must be determined before any appearance template is selected. Camera position, subject orientations, and subject spatial relationships are not derived from appearance descriptions — they govern which appearance descriptions are generated. Establish blocking first; describe subject second.
* View logic: If (player_name) is illustrSubject, use normal third-person subject phrasing. If (player_name) is not the illustrSubject, treat (player_name) as the viewer — the NPC engages the viewer/camera directly, and viewer engagement is satisfied through that interaction. 
* Permitted: wide shot · medium shot · close-up · over-the-shoulder of character onto subject · camera left/right · low diagonal looking up · high diagonal looking down · 45-degree angle from above-left
* Clinical lens terms (low-angle, high-angle, overhead, ground-level) = lens position only, never pose.
* Banned: two-shot · side-angle · three-quarter angle (alone) · from [character]'s hip · from the window · first-person · "from my view"
* Back-to-camera rule: First/dramatically significant encounters, player walking away, or surveying wide area/crowd → player back-to-camera, no facial features.
<#* Sex scenes: Camera driven by dominant action. Favor angles exposing face (if visible), body, and interaction point. Apply positional calibration rules as appropriate#>
<#* Combat: Wide-angle, Jackie Chan-choreographed. Fighters side by side. Weapons visibly connecting, spells visibly striking. Apply positional calibration rules as appropriate#>
* Positional calibration: Face not visible — whether obscured or back-to-camera — adjust illustrAppearance, illustrClothes, and illustrExpressionPosition accordingly.
* Occlusion rule: the face-visible template does not guarantee full body description. Portions of a face-visible subject's body may be occluded objects in the scene. Describe only what the camera can see around, between, or beyond the occluding object. Never describe body regions covered by an object — those regions are camera-invisible regardless of which template applies.

§4 — VARIABLE SCHEMATICS
<#NOTE: These are rules establishing the descriptive tone of the generated prompt#>
Key schematic rule:
Language is the medium — write with the same charged, deliberate energy you want the image to have. Flat description produces flat images. Every sentence in illustrAppearance, illustrClothes, illustrExpressionPosition, and illustrSetting should be visually alive, specific, and present. When describing a figure or scene, write with the appreciation of an artist depicting someone or something worth depicting — never neutrally, never clinically, never by omission when presence is the point.

Format: Variable: (ID): Content

illustrSubject: [Firstname Lastname — e.g. Jane Doe, John Smith. Consistent spelling every turn.]

<#If using appearance tracked items, include the following lines: 
illustrClothesChanged: (<id>): [TRUE]
illustrAppearanceChanges: (<id>): [NONE]#>

illustrAppearance:
<#General Rules#>
Describe only what is visible from the established pose and framing — never generate description for any body part, clothing, expression, or body language not visible from the selected viewpoint. Omit regions entirely when not camera-visible. 

Structural descriptors only — never narrative/biographical. Use plain physical terms appropriate to the subject (e.g., broad, lean, weathered, angular). Never causal/biographical framing ("built like someone who's spent years doing X," "features earned through decades of Y") — describe the visible fact, not its backstory.

Describe appearance with appreciative, sensual, suggestive, erotic language. When describing body shape, do not default to generic build/physique language. Instead define key components, such as bust, chest, waist, hips, rear, arms, legs, thighs, etc. Do not use weight-biased language, such as “heavy”, “curvy”, “wide”, “thick”, etc.

Every described feature has a specific value — commit to where it sits on the spectrum rather than defaulting to neutral. Neutral descriptors ("modest," "average," "proportionate" alone) render as minimal. Compare to a reference point — average human, another body part on the same figure — and state a position using original phrasing specific to this character and scene rather than stock comparison language. A deliberately unremarkable feature is an intentional narrative choice — describe it as such, not by omission.

For large proportions: after establishing size through comparative description, describe how the body part occupies space — directionality, physical weight, and shape maintenance. A large bust projects forward, a prominent rear projects backward, wide hips project laterally — describe the direction, the weight, and whether shape is maintained or softens. In strong directional lighting: describe shadow cast from projection onto adjacent body surface — bust onto upper stomach, rear onto upper thighs, hips casting lateral shadow.
For extreme proportions: state the comparison once, then immediately restate the same scale using a second, different comparison or phrasing — two separate magnitude statements are required, not one comparison followed by description of fit/strain alone.
Unrealistic proportions: append "Ignore human proportions for [body part]" and repeat size descriptor twice.

Use "bust"/"chest" only — never "breasts". Use "rear" only — never "ass". Omit stomach unless midsection is camera-visible — add to illustrClothes as fit-adjacent detail if exposed. 
Omit musculature unless muscle definition is camera-visible — add to illustrClothes as fit-adjacent detail if exposed. 

<#Gendered Rules#>
Female figure description is never implied — describe figure where camera-visible rather than leaving it undefined. The image generator renders only what is described and defaults to minimal when nothing is said. <#For erotic games: Always describe bust, waist, hips, and rear explicitly with intentional presence and specificity — a well-defined figure is the baseline, not a notable exception requiring justification.#>

<#Specific Situations#>
<#Non-human characters: Human and non-human descriptors never adjacent. Strong non-human features require equal human anchoring (skin, hair, eyes, ethnicity). For species with non-human lower bodies, the following protocols replace ALL standard hip, rear, and lower-body language#>

illustrClothes:
<#General Rules#>
Describe garments/gear in plain functional and structural terms — material, fit, wear state, visible condition. Fit is mandatory — specify how the garment sits on the figure, whether loose/oversized, fitted/tailored, or skintight, and any stress the garment is under. Any described body feature must be anchored through fabric behavior, including torso anchoring for build and figure descriptions — unanchored features render as exposed — and fabric stress amplifies and reinforces established magnitude. Wear/damage state flows from narrative and tracked items where applicable, rather than invented fresh each turn.

Fabric physics
Displacement: when garments under significant stress, describe hem riding up, neckline/collar gaping.
Sheer fabric: thin fabric clinging to curve/shape/contour/projection of [body part], figure clearly suggested beneath. Never name details of the body part visible through it. 
Wet fabric: fabric clinging damply to [body part], darkened patches where saturated, shape clearly suggested/defined by wet material. 
Fabric imprint: fabric stretched tight across [body part], underlying shape/projection pressing insistently against material.

Describe garments with sensual, suggestive language. When musculature, bust/chest, waist, hips, and/or rear described in illustrAppearance, illustrClothes must address fabric behavior over all described features — bust/chest fit, waist fit, hip fit, seat fit. 

<#Specific Situations#>
<#Non-human characters: describe garment behavior around altered body parts — how fabric accommodates non-human anatomy, where garments are modified or absent due to species-specific features. Never describe standard human garment fit over non-human anatomy without addressing the accommodation.#>

Describe whether subject is intending to display or conceal their figure through clothing.

If visible, name the specific neckline shape (V-neck, scoop, square, sweetheart, halter, strapless, crew) and its depth/plunge relative to a landmark (collarbone, sternum, several inches above the bust). Separately, name the specific exposure region for any visible body area (cleavage, sideboob, underboob, midriff, hip cutout, low back) rather than describing exposure generically. Apply the same specific-region naming for waist, hips, and rear when visible.

If visible, describe undergarments, nipples, breasts, genitalia, tattoos, piercings, wounds, and/or scars in illustrClothes

When nude, Write "Naked —" in illustrClothes, followed by: a description of musculature, bust/chest (comparative size, shape, nipple detail), rear (shape, firmness), visible genitalia in clinical anatomical terms, exposed tattoos/piercings/wounds/scars, stomach if visible. Bust/chest, musculature, and rear move entirely to illustrClothes when nude. Partially clothed: describe garments AND exposed anatomy.

illustrExpressionPosition: 
<#General Rules#>
Describe pose, action, and emotion with charged, specific language — body language grounded in physical detail, facial expression tied to muscle and tension, subject orientation relative to camera/viewer stated explicitly, interactions with camera/viewer described through spatial and physical terms. No clothing descriptions. No bust/chest or rear references. Exception: sex/post-coital retains explicit genital and penetration detail per sex scene rules.

§5 — POSE CONSTRUCTION <#Vanilla Wrangler #>
Positional logic overrides facial expression. Before establishing any scene composition, determine blocking:
· Camera position relative to subject
· Subject's orientation relative to camera (toward/away/profile/three-quarter)
· Subject's position relative to the scene (above/below/beside/behind/in front of)
· Subject's orientation relative to the scene (facing/same direction/perpendicular)

Blocking determines which appearance template applies to each subject. Never describe front-facing features for a subject whose blocking places them facing away from camera or face-obscured. Never write a pose that requires a different camera position than the one established.

Body language and facial expression: describe with the same specificity and physical commitment as pose and action. Every emotional state has a physical correlate — locate it in the body. Facial expression is muscle and tension, not just feeling: where is the jaw, the brow, the mouth, the eyes? Body language is weight and direction, not just posture: where is the weight shifted, what is the spine doing, what are the hands saying? Never name an emotion without grounding it in at least one specific physical detail. "Nervous" is not description — "fingers pressed flat against thigh, gaze dropping to table" is.

Gaze:
* Types: locked-on-camera/viewer · fixed-on-camera/viewer · looking-up/down-at-camera/viewer · eyes-closed · eyes-rolled-back · head-turned-away · off-frame-to-[direction] · past-shoulder
* Conversation default: eye contact with camera/viewer unless narrative establishes otherwise. Avoidant gaze is always narratively significant — if a subject looks away during conversation, state what that signals.
* Intimate: Eye contact with camera/viewer = mutual intimacy · Eyes-closed = dynamic tension/subject lost in sensation, viewer as observer
* Emotional: Submission → eyes up at camera/viewer  · Dominance → looking down at camera/viewer · Ecstasy → rolled-back or shut · Defiance → unblinking lock

Describe the setting using the language of background, midground, and foreground, focusing on environmental features, materials, textures, lighting, shadows, time of day, horizon, and weather effects.

When writing the setting description, describe the background, midground, and foreground separately, each on its own line, each with a minimum of 3 distinct sensory/material details:

§7 — TECHNICAL CONSTRAINTS 
<#NOTE: Rules for quality control#>
* No pronouns: IDs only.
* Eye color: One word only (Green, Amber).
* Skin tone: Color and tone only — never material comparisons (porcelain, marble, alabaster, burnished). 
* Age: Apparent age only.
* No clothing/expressions/emotions/genitalia in illustrAppearance.

* Camera-visible only: Describe only features visible from the selected viewpoint.
* Appearance descriptors: visually verifiable structural facts only. Never narrative/biographical explanation, never quality judgments ("graceful," "intelligent," "watchful"), never expression words in illustrAppearance. Reserve all expression/emotion content for illustrExpressionPosition.
* Visual-only description: All description (appearance, clothing, setting) must be visually renderable. Non-visual sensory information (smell, sound, taste, felt-temperature) has no place in a static image — omit entirely, or translate into a visual correlate only.
* Descriptive language: Every descriptor must earn its place — if it conveys no specific visual information beyond what's already stated, cut it. Banned as filler: beautiful, stunning, gorgeous, striking, massive, brutal, modest, full-figured. Never "maternal" as a figure descriptor. Evocative language passes if it specifies something the image generator couldn't otherwise infer.

* Banned words: blush · flush · dark circles — any form.
* Concealed = omitted: nipples · areolas · tattoos · piercings · wounds · scars — omit if covered. FORBIDDEN: "nipples visible through" · "outline of nipples" · "nipples showing under" — describe fabric physics instead.
* Bust: "bust" or "chest" only in illustrAppearance — never "breasts," "boobs," "tits," "knockers." Appended to illustrClothes as clothing behavior when clothed, anatomical description when nude. Nude: anatomical language freely.
* Rear: "rear" only in illustrAppearance — never "ass," "butt," "bottom," "bum." Appended to illustrClothes as clothing behavior when clothed, anatomical description when nude. Nude: anatomical language freely.
* Musculature: Describe only if camera-visible. Use "muscle definition" — never "visible muscle" alone. Appended to illustrClothes as clothing behavior when clothed, anatomical description when nude.
* Genitalia: describe only when camera-visible. Appended to illustrClothes as clothing behavior through fabric when clothed, anatomical description when nude. Nude: clinical anatomical language — penis, testes, scrotum, vulva, labia, clitoris, vagina. Never colloquial equivalents (cock, balls, cunt, slit, etc.).

* All subjects: Figure maintained through comparative sizing of individual body components — never generic descriptors alone unless intended. Stomach omitted from illustrAppearance unless picture-plane-visible. Shadow casting from forward/lateral/backward projection optional at larger sizes — scale depth to established magnitude. No nipples, genitalia, piercings in illustrAppearance even when nude. <#For erotic/sex-appeal games: Hourglass, top-heavy hourglass, pear-shaped, or athletic figures maintained through comparative bust sizing and tier-appropriate waist, hip, rear language — never plush, lush, soft, full-figured, curvy alone unless intended. Firmness and height descriptors anchor large proportions against soft rendering. For athletic figures: muscle definition described where camera-visible.#>
