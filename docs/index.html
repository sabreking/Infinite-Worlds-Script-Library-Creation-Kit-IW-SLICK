The Script Library 3.29

Open a page, copy the box, and paste it into your Infinite Worlds world. The pages cover picture scripts, how the story talks, notebooks the game keeps between turns, and named picture styles.

The scripts were written by KaapstadMK, with pieces from Xyphrax, Thyr, TWNT, Tori, Funky Munky, MrDrunkinDragon, WolfishGrimm, and SpacemanSpiff. Sabre built this copy-paste site.
