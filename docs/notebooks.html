Notebooks that update themselves.

Your look page already has Player Appearance and one NPC Appearance list. This page is the other notebooks. Copy a set together: the real notebook, the Update notebook, and the trigger.

The AI writes the Update notebook. The trigger copies that row onto the real notebook and clears the update row. A row is the whole record, so the Update notebook should hold the full row, not one changed field by itself.

Description (what this notebook is for)
<#Relationship Tracker#>
Named characters, their relationship tier to the player, and their connection.
Update rules (when to change it)
<#Relationship Tracker#>
Add any named character upon first meaningful interaction with the player. 
Update when a character's relationship with the player changes. 
When updating an existing entry, ALWAYS match by name field and/or aliases field — never by list position. DO NOT rewrite other entries. NEVER update an entry whose name field and/or aliases field does not match the character being updated. Update ONLY changed fields.
If two tracked characters are in a relationship with each other, note it in their respective connection fields. 
Remove entries ONLY if the character permanently exits the narrative.

If a character's name changes or aliases are revealed, append the new name to aliases. DO NOT update the name field. DO NOT generate a new entry under a new name

Relationship tiers in ascending narrative significance:
acquaintance · colleague · co-worker · friend · close friend · romantic interest · partner · co-parent · rival · mentor · family

Mark significant: true for friend tier and above, plus rival, mentor, and family regardless of tier. Mark significant: false for acquaintance, colleague, and co-worker unless narrative circumstances warrant otherwise.

connection: one-line description of relationship to player, 10 words maximum.

The trigger

Name the trigger exactly: Relationship Updater

Trigger name
Relationship Updater

Turn on “can trigger more than once.”

Condition. Type: PawScript. Paste this check.

PawScript condition
$relationship_update.any(name.exists())

Effect. Type: Run a script. Paste this script.

Run a script
#Relationship Updater
for each $char_update in $relationship_update
  if $relationship_tracker.any(name.exists()) = false
    $relationship_tracker = list()
    $relationship_tracker.append($char_update)
  else if $relationship_tracker.any(name = $char_update.name) or $relationship_tracker.any(aliases contains $char_update.name)
    $relationship_tracker.where(name = $char_update.name or aliases contains $char_update.name) = $char_update
  else
    $relationship_tracker.append($char_update)
  $relationship_update.remove($char_update)

Settings on the Items to track screen

  • Visible to: everyone

Description (what this notebook is for)
<#Intimacy Log#>
A record of significant intimate encounters between the player character and other characters — emotional and physical milestones that the narrative should reference naturally going forward.
Update rules (when to change it)
<#Intimacy Log#>
One entry per named character or named group. Never create multiple entries for the same character or group. Update encounter_count and current_register after each subsequent encounter — do not append new entries for repeat encounters. For group encounters involving 3+ participants, create a single group entry listing all participants rather than individual entries per person.

Add an entry only after a milestone has fully and completely occurred in narrative. Never log anticipated, imminent, or in-progress events.

Milestone options (only these — do not create or subdivide categories):
first emotional vulnerability / first kiss / first sexual encounter / first transformation-related intimate encounter / first explicit acknowledgment of feelings / first serious conflict and resolution / first morning after / first coven bonding

Additional milestones may be logged only when an event represents a genuine first-time relationship shift not covered by the standard list.

current_register: one line, 10 words maximum — current emotional and intimate register, updated to reflect most recent encounter.
Example of how it should look
- name: Hermione Granger
  first_encounter: Day 3, evening
  encounter_count: 4
  milestone: first sexual encounter
  current_register: deeply bonded, coven resonance active, comfort and intensity both high
- name: Full Coven — Hermione, Parvati, Daphne, Susan, Luna, Padma, Lavender
  first_encounter: Day 7, September 6th
  encounter_count: 2
  milestone: first full coven bonding
  current_register: magically resonant, power surge confirmed, bonds deepened collectively

  first_encounter: text

#Intimacy Updater
for each $entry in $intimacy_update
  if $intimacy_log.any(name.exists()) = false
    $intimacy_log = list()
